================================================================================
DOCUMENT 03 — ViewModel Behavior Guide
TYPE: ViewModel Specification
================================================================================

PURPOSE
-------
Defines how the ViewModel handles binding, validation, dependencies, and button
behavior. Prevents incorrect UI behavior and inconsistent JSON updates.

BINDING RULES
-------------
- Every UI control must bind to a ViewModel property.
- Binding must be TwoWay for editable fields.
- Binding must be OneWay for display-only fields.

VALIDATION RULES
----------------
- Numeric inputs must reject invalid values.
- Sliders must clamp values to allowed ranges.
- Dropdowns must only accept predefined options.
- Validation must preserve the previous valid value when input is rejected.

DEPENDENCY RULES
----------------
- Dependencies are defined and enforced in the ViewModel.
- A dependent control must be disabled while its required parent condition is
  inactive.
- Examples in implementation code must use property names that exist in the
  approved model/JSON specification.

BUTTON RULES
------------
Apply:
  - Save changes to JSON
  - Keep window open

OK:
  - Save changes to JSON
  - Close window

Cancel:
  - Close window without saving

Reset:
  - Restore defaults for current module only
