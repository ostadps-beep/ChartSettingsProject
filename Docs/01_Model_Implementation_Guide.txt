DOCUMENT 01 — Model Implementation Guide
TYPE: Core Model Specification
================================================================================

PURPOSE
-------
This document defines how the ChartSettingsModel and all sub-models must be
implemented. It ensures consistent JSON structure and prevents model confusion.

MODEL STRUCTURE
---------------
ChartSettingsModel.cs contains the root object with the following sub-models:

1. ChartModel
2. AxesModel
3. CandlesModel
4. GridBackgroundModel
5. DrawingToolsModel
6. AnalyticalModulesModel
7. HudOverlayModel
8. PerformanceModel
9. WorkspaceModel
10. AdvancedModel

JSON MAPPING
------------
The model class names map to the JSON category names as follows:
- ChartModel → Chart
- AxesModel → Axes
- CandlesModel → Candles
- GridBackgroundModel → Grid
- DrawingToolsModel → Tools
- AnalyticalModulesModel → AnalyticalModules
- HudOverlayModel → HUD
- PerformanceModel → Performance
- WorkspaceModel → Workspace
- AdvancedModel → Advanced

IMPLEMENTATION RULES
--------------------
- All fields must match the JSON specification exactly.
- All numeric fields must use the default value defined for that field.
- All boolean fields must use the default value defined for that field.
- All color fields must be stored as HEX (#RRGGBB).
- No additional fields may be added.

OUTPUT RULES
------------
The model must always produce valid JSON matching the defined structure.
