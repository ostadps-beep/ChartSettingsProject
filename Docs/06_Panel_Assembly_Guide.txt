DOCUMENT 06 — Panel Assembly Guide
TYPE: UI Assembly Specification
================================================================================

PURPOSE
-------
Defines how the complete Chart Settings Panel is assembled from its 10 UI
modules and shared window elements.

STRUCTURE
---------
WINDOW
- Title bar
- Sidebar (10 categories)
- Header (title + description)
- Content area (module content)
- Footer buttons (Apply, OK, Cancel, Reset)

SIDEBAR ORDER
-------------
1. Chart
2. Axes
3. Candles
4. Grid & Background
5. Drawing Tools
6. Analytical Modules
7. HUD & Overlay
8. Performance
9. Workspace
10. Advanced

MODULE LOADING RULES
--------------------
- Only one module is visible at a time.
- Switching sidebar items replaces the content area.
- Header updates based on the selected module.

FOOTER BUTTON RULES
-------------------
Apply → save changes, keep window open
OK → save changes, close window
Cancel → close window without saving
Reset → restore defaults for current module only
