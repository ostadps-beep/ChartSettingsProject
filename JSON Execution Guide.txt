================================================================================
DOCUMENT 01: JSON Execution Guide
TYPE: Implementation Rules
================================================================================

PURPOSE
-------
This document defines how the Chart Settings JSON must be created, validated,
saved, loaded, and applied to the UI. It prevents model confusion and ensures
consistent behavior across all modules.

JSON STRUCTURE
--------------
The JSON tree must follow the exact structure defined in ChartSettingsModel.cs.
Each category (Chart, Axes, Candles, Grid, Tools, HUD, Performance, Workspace,
Advanced, AnalyticalModules) must appear as a top-level object.

Example:
{
  "Chart": { ... },
  "Axes": { ... },
  "Candles": { ... },
  ...
}

VALIDATION RULES
----------------
- All numeric values must be validated against their allowed ranges.
- All color values must be stored as HEX (#RRGGBB).
- All toggles must be boolean (true/false).
- Dropdowns must store the selected option as string.

SAVE RULES
----------
- JSON must be saved only when Apply or OK is pressed.
- Cancel must NOT modify the JSON.
- Reset must restore only the current category.

LOAD RULES
----------
- JSON must be loaded on startup.
- UI must reflect JSON values immediately after loading.

APPLY RULES
-----------
- Apply updates the JSON but keeps the window open.
- OK updates the JSON and closes the window.
