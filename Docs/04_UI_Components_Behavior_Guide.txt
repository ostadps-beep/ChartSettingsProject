================================================================================
DOCUMENT 04 — UI Components Behavior Guide
TYPE: Component Behavior Specification
================================================================================

PURPOSE
-------
Defines exact behavior of all reusable UI components used in the Chart Settings
Panel.

COMPONENTS
----------

SLIDER
------
- Output: integer
- Range: defined per module
- Event: OnValueChanged → updates ViewModel

TOGGLE
------
- Output: boolean
- Event: OnChecked / OnUnchecked → updates ViewModel
- Dependencies are controlled by the ViewModel.

DROPDOWN
--------
- Output: string (selected option)
- Options must match the specification exactly.
- No arbitrary options may be introduced by the UI.

COLOR PICKER
------------
- Output: HEX color (#RRGGBB)
- Event: OnColorChanged → updates ViewModel

NUMERIC INPUT
-------------
- Output: integer
- Validation: must reject non-numeric input.

VALIDATION AND DEPENDENCY BOUNDARY
----------------------------------
- UI components handle presentation and user input events.
- ViewModel handles validation, dependencies, and state rules.
- UI components must not independently redefine model or JSON rules.
