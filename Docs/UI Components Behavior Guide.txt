================================================================================
DOCUMENT 02: UI Components Behavior Guide
TYPE: Component Behavior Specification
================================================================================

PURPOSE
-------
Defines exact behavior of all UI components used in the Chart Settings Panel.

COMPONENTS
----------

SLIDER
------
- Output: integer
- Range: defined per module
- Event: OnValueChanged → updates ViewModel immediately

TOGGLE
------
- Output: boolean
- Event: OnChecked / OnUnchecked
- Dependencies: may enable/disable other controls

DROPDOWN
--------
- Output: string (selected option)
- Options must match the specification exactly.

COLOR PICKER
------------
- Output: HEX color (#RRGGBB)
- Event: OnColorChanged → updates ViewModel

NUMERIC INPUT
-------------
- Output: integer
- Validation: must reject non-numeric input

DEPENDENCY RULES
----------------
- If a control depends on another, it must be disabled until the parent is active.
- Dependencies must be defined in ViewModel.
