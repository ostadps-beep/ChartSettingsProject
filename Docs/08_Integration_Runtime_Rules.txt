================================================================================
DOCUMENT 04 — Integration & Runtime Rules
TYPE: Integration Specification
================================================================================

PURPOSE
-------
Defines how JSON, ViewModel, and Python/C++ Bridge interact during runtime.

JSON RULES
----------
- JSON must follow the exact structure defined in Model.
- JSON must be saved only on Apply or OK.
- JSON must be loaded on startup.
- JSON must never contain undefined fields.

PYTHON/C++ BRIDGE RULES
-----------------------
- Communication must use TCP.
- All messages must follow the protocol:
  SETTINGS.UPDATE { key, value }
  SETTINGS.APPLIED { status, changed[] }
  SETTINGS.SAVE { path }

RUNTIME RULES
-------------
- UI → ViewModel → JSON → PythonBridge
- JSON → ViewModel → UI
- No new fields may be added at runtime.
- No UI components may be generated dynamically.

FINAL VERIFICATION
------------------
Before closing the window:
- Validate all fields
- Ensure JSON is consistent
- Ensure no dependency conflicts exist
