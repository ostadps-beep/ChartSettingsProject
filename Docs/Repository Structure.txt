================================================================================
PROJECT: ChartSettingsPanel
TYPE: Unified Repository Structure
================================================================================

CORE C# FILES
-------------
1. ChartSettingsModel.cs
   - Defines full JSON Tree as strongly typed data classes.
   - Provides serialization/deserialization for saving and loading settings.

2. ChartSettingsViewModel.cs
   - Handles bindings between UI and model.
   - Implements dependencies, immediate vs. apply logic, and button behavior.

3. PythonBridge.cs
   - TCP protocol bridge to Python/C++ analytical engine.
   - Manages host, port, timeout defined in Advanced settings.

4. ColorPicker.cs
   - WPF-native helper for color selection.
   - Converts selected colors to Hex (#RRGGBB).

UI XAML FILES
-------------
5. Advanced.xaml
   - Advanced engine and threading options.

6. AnalyticalModules.xaml
   - Analytical modules configuration (parameters, display, alerts).

7. AxesSettings.xaml
   - Price/Time axes settings (position, decimals, colors).

8. CandleSettings.xaml
   - Candle rendering (bull/bear colors, wick/body thickness).

9. ChartSettings.xaml
   - Main settings window (sidebar, header, content, footer buttons).

10. DrawingTools.xaml
    - Drawing tools (color, style, snapping, drag behavior).

11. GridBackground.xaml
    - Grid and background styling (colors, transparency, gradient).

12. HudOverlay.xaml
    - HUD overlay (items, position, fonts, transparency).

13. Performance.xaml
    - Performance tuning (FPS, GPU acceleration, buffer size).

14. Workspace.xaml
    - Layout management (save, load, reset, import/export).

SPECIFICATION DOCUMENT
----------------------
15. ChartSettings_Specification.txt
    - Unified full specification including:
      * JSON Tree
      * UI model
      * Button behavior
      * Event logic
      * Input/Output protocol

SUMMARY
-------
- Total files: 15
- Purpose: Unified chart settings panel with modular UI (10 XAML files),
  core logic (4 C# files), and one master specification document.
- Execution Path:
  * JSON Tree → implemented in ChartSettingsModel.cs
  * UI → defined in XAML files, bound to ViewModel
  * Behavior & dependencies → handled in ChartSettingsViewModel.cs
  * External engine communication → via PythonBridge.cs
  * Color selection → via ColorPicker.cs
